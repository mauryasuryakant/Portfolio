# Suryakant Maurya — Portfolio

A calm, responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## What’s inside
- Five sections: Home, About, Selected Work, Stack & Focus, and Contact.
- A distinct accent palette for each section, with a dark/light appearance toggle.
- Responsive navigation, previous/next page controls, and browser history support.
- Project links, mail links, and a working copy-email action.
- No framework runtime, build pipeline, environment variables, or external API.

## Run locally
Open index.html in a browser, or run:

    python -m http.server 8000

Then visit http://localhost:8000.

## Personalise
Edit project names and links in script.js. Profile and contact details are in index.html and script.js. The design tokens and responsive layouts are in styles-1.css through styles-4.css.

## Deploy
Connect this repository to Vercel. It is a static site, so no build command or output directory is required.
